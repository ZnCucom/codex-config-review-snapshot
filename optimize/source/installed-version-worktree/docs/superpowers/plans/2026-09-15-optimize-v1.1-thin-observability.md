**Goal:** Add repository-external task summaries, reviewer evidence archives, and scoped exports to the existing Optimize CLI and Skill, then validate the fixed candidate for controlled user-level installation.

**Architecture:** Keep `scripts/optimize_context.py` as the public standard-library CLI and put the focused storage/formatting implementation in a small sibling `scripts/optimize_observability.py` module. Store deterministic JSON plus derived Markdown under `%LOCALAPPDATA%\Optimize\observability`, keyed by a hash of repository/worktree identity and a stable task archive ID; preserve review bodies separately from computed metadata. Extend the Skill with model-driven natural-node calls only, never hooks, polling, `.agent` creation for LIGHTWEIGHT work, or automatic context loading.

**Tech Stack:** Python standard library, `unittest`, Git, Markdown, JSON.
