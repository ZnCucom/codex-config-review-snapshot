# Optimize v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build a repository-visible, executable context-state workflow that can resume Teaching AI milestones deterministically and prevent short agent polling without reducing correctness or review guarantees.

**Architecture:** Exact facts stay in existing L0 sources. Small tracked Markdown files provide navigation and current state, an ignored active file holds ephemeral work, a short skill controls agent behavior, and one dependency-free Python CLI validates state, renders packets, and extracts rollout metrics.

**Tech Stack:** Markdown, Git, Python 3.11+ standard library (`argparse`, `json`, `pathlib`, `subprocess`, `tomllib`, `unittest`).

**Spec:** `docs/superpowers/specs/2026-09-13-context-efficiency-design.md`

## Global Constraints

- Teaching AI business behavior, public/domain/protocol contracts, schema, and production source are out of scope.
- Repository evidence outranks operational state; operational state outranks conversation memory.
- Tests and independent review remain complete.
- No production dependency, daemon, state database, opaque memory, or experimental context feature.
- No unsupported Codex configuration keys.
- `.agent/project-map.md` <= 8 KiB, `.agent/current-milestone.md` <= 12 KiB, `.agent/active.md` <= 4 KiB.
- Short wait means less than 300 seconds. Normal agent waits use one 5-30 minute bounded call and return early on activity/completion.
