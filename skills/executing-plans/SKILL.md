# Execute an Existing Plan

Read the relevant plan and verify its assumptions against current source. Clarify material contradictions; do not repeat approval already given for reversible work.

Astra normally executes the work directly in the current session. Use coherent units, necessary reads and proportionate verification. Reuse unchanged successful evidence. Track progress only as much as the work requires; do not create todos for every small action.

Delegation is optional when substantial independent work or risk-based independent review warrants it. Do not switch to SDD merely because subagents are available. A plan, one review or a temporary agent does not automatically require STATEFUL.

At useful boundaries, report evidence and actual remaining work. For integration/branch decisions consult finishing-a-development-branch when relevant, honoring existing authorization. Do not start extra reviews, commits, pushes or a new workflow merely to finish the plan.
