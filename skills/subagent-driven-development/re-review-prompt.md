# Optional Follow-up Review Brief

Use when fixes warrant independent checking. Provide the original findings, relevant requirement, fix diff and updated evidence.

Verify the addressed findings and material regressions introduced by the fix. Avoid reopening unrelated areas without new evidence. Reuse still-valid tests; run only checks needed for remaining uncertainty.

Return addressed/open findings and their evidence. At most two consecutive substantive fix/re-review rounds use the same strategy. If still unresolved, the controller must revisit requirements, diff, reviewer interpretation and verification before choosing a new explicit strategy. Do not prescribe static model/tool parameters or automatic additional reviewers.
